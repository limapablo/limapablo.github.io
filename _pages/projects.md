# Projects

A selection of projects that demonstrate how I approach analytics, automation, machine learning and business problems end to end.

## IT Service Desk Analytics

**Python · PostgreSQL · SQL · Power BI · Operational Analytics**

An end-to-end analytics project based on public IT service desk data from IFPA. The work is designed to go beyond dashboarding by covering ingestion, data quality, SQL modeling, KPI design and executive reporting.

**Key themes:**
- multi-year data ingestion and validation;
- operational KPI design;
- backlog and resolution-time analysis;
- analytical SQL and reusable views;
- Power BI semantic modeling;
- business-oriented recommendations.

[View repository](https://github.com/limapablo/it-service-desk-analytics){: .btn .btn--primary }

## Municipal Sanitation & Education Clustering

**Python · Scikit-learn · K-Means · QGIS · Geospatial Analysis**

My MBA capstone project at USP/ESALQ, focused on identifying patterns across Brazilian municipalities using sanitation and education indicators.

The analysis combines unsupervised learning with geospatial interpretation and later evolved into a scientific publication.

**What it demonstrates:**
- exploratory data analysis;
- feature scaling and clustering;
- geospatial data integration;
- interpretation of unsupervised models;
- technical communication in an academic context.

[View repository](https://github.com/limapablo/kmeans-saneamento-educacao){: .btn .btn--primary } [Open publication](https://doi.org/10.29327/23189258.1068040){: .btn }

## Rental Price Prediction

**Python · XGBoost · Streamlit · Scikit-learn**

A supervised machine-learning project for estimating residential rental prices in Brazil's Federal District.

The repository documents the complete workflow from exploratory analysis and preprocessing to model deployment and limitations.

**What it demonstrates:**
- supervised regression;
- feature engineering;
- model comparison and evaluation;
- model persistence;
- interactive deployment with Streamlit;
- model documentation through a Model Card.

## Intelligent Debt Amortization Simulator

**n8n · JavaScript · Automation · Financial Modeling · Monte Carlo**

A decision-support workflow that compares alternative financial strategies using live Brazilian macroeconomic data and automated calculations.

The project combines orchestration, financial modeling, sensitivity analysis and Monte Carlo simulation in a single reproducible workflow.

**What it demonstrates:**
- workflow automation with n8n;
- API integration;
- JavaScript-based analytical logic;
- scenario modeling;
- decision-support design;
- documentation of assumptions and limitations.

[View repository](https://github.com/limapablo/n8n_simulador_de_amortizacao_inteligente){: .btn .btn--primary }

## Portfolio Philosophy

I try to build projects that are useful as **evidence of capability**, not just as code samples.

That means documenting the problem, making assumptions explicit, keeping the workflow reproducible and showing how technical work connects to a real analytical or business decision.
