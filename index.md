## Selected Projects

### IT Service Desk Analytics

**Python · PostgreSQL · SQL · Power BI**

End-to-end operational analytics project using multi-year IT service desk data to study workload, backlog, resolution patterns and operational bottlenecks. The project is structured as a full analytics workflow, from ingestion and validation to SQL modeling and executive reporting.

[Explore the project](https://github.com/limapablo/it-service-desk-analytics){: .btn .btn--primary }

---

### Municipal Sanitation & Education Clustering

**Python · Scikit-learn · K-Means · QGIS**

Applied data science research developed as my MBA capstone at USP/ESALQ. The project uses unsupervised learning and geospatial analysis to identify municipal profiles across Brazil based on sanitation and education indicators.

The work later evolved into a scientific publication with DOI **10.29327/23189258.1068040**.

[View project](https://github.com/limapablo/kmeans-saneamento-educacao){: .btn } [Publication](https://doi.org/10.29327/23189258.1068040){: .btn }

---

### Rental Price Prediction

**Python · XGBoost · Streamlit · Machine Learning**

A supervised machine-learning project for residential rental price estimation in Brazil's Federal District, covering data preparation, model evaluation, deployment and model documentation.

[View project](https://github.com/limapablo/rental-price-prediction){: .btn } [Live app](https://rental-price-prediction-apktbzfvgnenub8uc4bxrv.streamlit.app/){: .btn .btn--primary }

---

### Intelligent Debt Amortization Simulator

**n8n · JavaScript · Automation · Financial Modeling**

A decision-support workflow that combines Brazilian macroeconomic data, financial modeling and Monte Carlo simulation to compare debt amortization, investing and financing strategies.

[View project](https://github.com/limapablo/n8n_simulador_de_amortizacao_inteligente){: .btn }
